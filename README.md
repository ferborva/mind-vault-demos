# Demos

Playable prototypes. Early, rough, and meant to be tried rather than admired.

## Six Moves

A ten-minute game about seeing a problem a second way. It teaches six named reframing
moves, then asks you to use them — you write your own version before you're shown
another one, and nothing you write is scored or stored.

**▶️ [Play it](https://ferborva.github.io/mind-vault-demos/)**

Runs entirely in your browser. No account, no network, no tracking, nothing saved.
Two tracks — one for roughly ages 9–13, one for 14+.

*Feedback welcome, especially the unflattering kind: which bit was boring?*
