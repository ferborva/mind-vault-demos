# Demos

Playable prototypes. Early, rough, and meant to be tried rather than admired.

## The Memory Trick

Five minutes. You'll be shown some things and asked to remember them — then taught
a trick that magicians use, and asked again. **Your own score is the point.**

No typing anywhere. Best for roughly ages 8 and up.

**▶️ [Play it](https://ferborva.github.io/mind-vault-demos/memory/)**

## Six Moves

A ten-minute game about seeing a problem a second way. It teaches six named reframing
moves, then asks you to use them. You write your own version before you're shown another
one, and nothing you write is scored or stored.

Aimed at teenagers and adults — **it was tested on younger children and was too abstract
for them.** That's what prototypes are for.

**▶️ [Play it](https://ferborva.github.io/mind-vault-demos/)**
